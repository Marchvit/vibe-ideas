# Идеи для вайб-кодинга

Дневник идей для телефона (PWA). Идеи хранятся на самом устройстве.
Три статуса: идея → в работе → готово. Синхронизация с компьютером — через файл
(«Сохранить в файл» на одном устройстве, «Загрузить из файла» на другом).

## Запуск
- На компьютере: открыть `index.html` через Live Preview в VS Code (просто двойной клик не сработает — нужен сервер).
- На телефоне: открыть адрес сайта в браузере → меню → «Добавить на главный экран».
- Тесты: `node --test`
